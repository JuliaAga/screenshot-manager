# Contributing

Use Python 3.11+; the app has no Python package dependencies. Follow the README to run it and docs/VERIFICATION.md to reproduce checks. Keep changes focused and describe the behavior and checks in your pull request.

Run `python3 -m unittest discover -s tests -v` and `node --check app/static/app.js` before submitting. Use synthetic screenshots and temporary data for tests. Do not include API keys, passwords, collection databases, personal screenshots, server backups, or private hostnames in commits or issues.
